# Security policy

## Reporting a vulnerability

If you find a security problem in TALLYTAG, **please report it privately. Do not open a public issue, pull request or discussion about it.**

1. Go to the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what you think its impact is.

This uses GitHub's private vulnerability reporting, so only the project maintainers can see your report. We will reply as soon as we can, keep you informed while we fix it, and credit you when the fix is published if you would like that.

## What counts

Anything that could let someone see, change or delete information they should not, take over a session, or get around a check. If you are unsure, report it anyway.

## Secrets and real data

If you notice a password, key or token, or anything that looks like real personal or official data, in this repository or its history, report it the same way, privately. Please do not copy or share it.

## Supported versions

TALLYTAG is in early development. Fixes are made on the `main` branch and included in the next release.
